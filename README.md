## 💀 The Problem

You're building your GitHub profile, updating your resume, or prepping a portfolio and you hit the same wall every time:

> *"I know I use stuff... but what do I actually list?"*

You spend 45 minutes staring at a blinking cursor. You forget half the tools you use daily. You undersell your stack. You Google "cybersecurity skills list" and get a blog post from 2019 that lists "firewalls" as a skill.

**ProfileBuilder fixes that.**

---

## 🧠 The Solution

Three brutally comprehensive, copy-paste-ready skill templates covering the entire tech career spectrum:

```
📄 Cybersecurity_Skills_Master_Template.md    → Offense, Defense, Cloud, GRC, Certs
📄 IT_Skills_Master_Template.md               → Helpdesk → Sysadmin → Architect
📄 DevOps_SRE_Skills_Master_Template.md       → CI/CD, K8s, IaC, SRE, Platform Eng
```

Each template includes:
- **Categorized skill blocks** you can copy directly into any profile
- **GitHub display formats** (shields.io badges, tables, minimalist lists)
- **Role-specific starter packs** so you grab exactly what fits your level
- **Customization tips** to make generic lists sound like *your* experience

## 📋 Usage

### For GitHub Profiles

1. Pick a template → Copy the skills that match your experience
2. Choose a display format (badges, table, or minimalist list)
3. Paste into your `README.md` profile repo
4. Customize with your specific tools, versions, and context

### For Resumes

1. Grab the role-specific starter pack closest to your target role
2. Remove anything you can't speak to in an interview
3. Add specifics: years of experience, scale, environment context

### For LinkedIn / Portfolios

1. Use the categorized blocks as a skill inventory
2. Translate to LinkedIn skill endorsements
3. Reference in project descriptions and role summaries

### For Interview Prep

1. Review the template for your target role
2. For each listed skill, prep a "time I used this" story
3. Identify gaps → build a study plan

## 🤝 Contributing

Got a tool, cert, or category we missed? **PRs are welcome.**

1. Fork the repo
2. Add your skills to the appropriate template
3. Keep the formatting consistent (code blocks for tool lists, tables for overviews)
4. Submit a PR with a brief description of what you added and why

**Ground rules:**
- Only add tools/skills you've actually used or can vouch for
- Keep descriptions concise — this is a reference, not a textbook
- If a tool is dead or deprecated, note it (don't just remove — someone might still encounter it)
- New role starter packs are always welcome
