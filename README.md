---

## How to Use This Template

1. **Pick your sections** — Not everything applies to every role. A pentester's profile looks different from a SOC analyst's.
2. **Be honest** — List what you actually use, not what you've heard of. Interviewers will ask.
3. **Show depth** — Star (⭐) or bold your strongest skills so readers know where you go deep vs. wide.
4. **Keep it current** — Tools change fast. Review quarterly.

## ✏️ Customization Tips

- **Be specific about versions/depth:** "Splunk (5+ years, custom dashboards, ES)" > "Splunk"
- **Link to projects:** If you built a tool or wrote a detection, link to the repo
- **Show context:** "CrowdStrike Falcon (RTR, threat hunting, IOA tuning)" > "CrowdStrike"
- **Remove fluff:** If you did a TryHackMe room on it once, maybe don't list it
- **Group by strength:** Lead with your strongest domain (offense, defense, cloud, etc.)
- **Update after every project:** New engagement = new tools to add
